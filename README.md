Обрана платформа ATtiny85.
Це код проєкту для ATtiny85, зроблений у Wokwi. 
Компонентами є мікроконтролер, світлодіод та резистор.
В ньому кожну секунду змінюється стан світлодіоду на протилежний: ввімкнений на вимкнений і навпаки.
